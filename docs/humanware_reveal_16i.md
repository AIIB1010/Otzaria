# שימוש באוצריא במסך HumanWare Reveal 16i

מהדורה זו מיועדת לקריאה מקרוב ולראייה מוגבלת. היא תומכת ב-Android 7.0
ומעלה (API 24), וכוללת כברירת מחדל טקסט, כפתורים, שדות חיפוש וסרגל ניווט
גדולים. גודל הטקסט של הספר מתחיל ב-30 וגודל המפרשים ב-26; אפשר לשנות אותם
מתוך הגדרות הטקסט באפליקציה.

## 6-Key Macro Pad עם גלגלת

ל-Macro Pad אין פרוטוקול אוניברסלי: כל יצרן בוחר אילו מקשי מקלדת הוא שולח.
לכן האפליקציה מזהה את כל מקשי F13 עד F24 כקיצורים שאפשר לבחור במסך
`הגדרות > קיצורי מקלדת`.

הגדרה מומלצת לפד בעל שישה מקשים:

| מקש שהפד שולח | פעולה להגדיר באוצריא |
| --- | --- |
| F13 | ספרייה |
| F14 | חיפוש בספר הפתוח |
| F15 | חיפוש חדש בכל הספרים |
| F16 | הגדלת הטקסט / התצוגה |
| F17 | הקטנת הטקסט / התצוגה |
| F18 | הגדרות |

הגדר את הסיבוב עם כיוון השעון ל-`Page Down`, את הסיבוב נגד כיוון השעון
ל-`Page Up`, ואת לחיצת הגלגלת ל-`F14` או ל-`Ctrl+F`. אלו מקשי HID סטנדרטיים
שאינם תלויים בתוכנת היצרן של הפד. אם הפד כבר שולח מקשים אחרים, אפשר פשוט
לבחור אותם במקום F13–F18 במסך קיצורי המקלדת; אין צורך לשנות את הקוד.

## בדיקה לפני המכשיר

APK יכול לרוץ באמולטור שמוגדר ל-API 24 וביחס מסך דומה למסך רחב. האמולטור
מאמת את תאימות Android ואת גודל הממשק, אבל אינו מאמת את דרייבר ה-Macro Pad
או את המראה האופטי המדויק של Reveal 16i. לפני הפצה יש לבדוק התקנה אמיתית
אחת על המכשיר ולוודא שהפד מזוהה כמקלדת Bluetooth/USB רגילה.
